Guide til Spotify Client ID
Hitsters redirect URI
http://127.0.0.1:5187/callback
  1. Gå til Spotify Developer Dashboard og log ind med din Spotify-konto.
  2. Vælg Create app. Kald den fx Hitster Local, og vælg Web API, hvis Spotify spørger om API.
  3. Indsæt redirect URI'en ovenfor under Redirect URIs. Brug 127.0.0.1, ikke localhost.
  4. Gem appen, åbn dens oversigt eller settings, og kopier feltet Client ID.
  5. Sæt Client ID'et ind her i Hitster, tryk Gem ID, og derefter Log ind.

Du skal ikke bruge Client Secret til denne lokale browser-login. Spotify Premium skal være aktivt på kontoen, der styrer afspilningen.
