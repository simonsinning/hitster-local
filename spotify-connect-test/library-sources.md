# Hitster Local song-library sources

This file tracks the sources used as inspiration for the built-in library.
The app does not copy full playlist/list contents wholesale. Sources are used
to seed candidates, then the local library keeps our own balanced selection.

- DR Top100: Den officielle liste over Danmarks bedste sange

- DR Top100 project context
  - https://www.drkoncerthuset.dk/artikler/2026/juni/top100-sangene-der-samler-os/
- P3's Uundgåelige archive
  - https://andyg.dk/p3trends/unavoidables
- GAFFA recent Danish/international annual coverage
  - https://gaffa.dk/nyheder-fra-gaffa/2025/marts/her-er-vinderne-af-gaffa-prisen-2025/
